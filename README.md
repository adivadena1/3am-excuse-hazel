A hardware wallet's excuse for refusing to sign a transaction at 3 AM — one tight line, in the device's own voice. It has signed this exact swap twice before and is not doing it a third time.

## Run it

```sh
node main.ts
```

It writes a single line (under 200 characters) to `/output/entry.txt`.
